# montest

- Do not use more than 16 cores (parallel workers, `mclapply`/`parLapply`, `future` plans, etc.).

## Interaction preferences

- Be short and concise. No filler.
- If unsure, stop and ask — don't guess.
- Use Stata 19, not Stata 18.
- When writing text in .tex files, do not add line breaks within paragraphs.
- When reading a PDF and extracting its text, save the extracted clean text as a
  `.txt` file alongside the PDF (same name, same folder), so future reads can use
  that instead of re-extracting.
